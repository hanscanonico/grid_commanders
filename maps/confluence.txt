# Four rivers, one sea: every army fields ground, air and sea from its own corner.
# The flagship, and the largest board the game ships. Seats sit at the corners in
# reading order -- 1 NW, 2 NE, 3 SE, 4 SW -- so the fair duel is an opposite pair,
# 1 against 3 or 2 against 4. A 32x24 rectangle cannot be turned a quarter turn onto
# itself, so the four homes are congruent by the rectangle's own symmetry instead:
# an opposite pair maps onto the other by a half turn exactly, an adjacent pair by a
# mirror. Every seat is the same walk from the middle and an opposite pair the same
# walk from each other; only the two edge runs differ, because the board is wider
# than it is tall. No `# symmetric` tag: that lint is a duel instrument.
# Each corner holds two bases, an airport and a port, so one seat can field the whole
# roster -- which is the question a 3v1 asks here: which domain will the three
# neglect? The tidal arm that starts at each home port runs down into the central sea,
# so all four fleets share one body of water and none needs a ferry to meet another
# (naval R1). The land is one piece for the same reason: every arm stops short of the
# board edge, so the coast walks around every one of them and every army can march on
# every other. Four neutral docks make the harbour island where the arms meet -- a
# lander's prize, since nothing walks there. The freshwater tributary beside each home
# is foot-only; the home road bridges it, and that bridge is the tributary's one
# crossing within the home band -- not a gate on the corner, which stays open to
# wheels and tracks around the arm's end along the perimeter road.
