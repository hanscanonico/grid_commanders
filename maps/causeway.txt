# Four island homes chained by causeways: the armies walk, the fleets fight for the crossings.
# Grand board, 30x22. Seats sit at the corners in reading order - 1 NW, 2 NE,
# 3 SE, 4 SW - so the opposite pairs 1&3 and 2&4 make the fair duel.
#
# A 30x22 rectangle cannot be turned a quarter turn onto itself, so a true
# 90-degree layout is impossible here. The board carries the rectangle's whole
# symmetry group instead: it is identical under a half turn and under both
# mirror axes, which makes all four corner seats congruent to each other - the
# guarantee a quarter turn would have bought. No `# symmetric` tag: that one is
# a two-army instrument and this board seats four.
#
# The causeways are the whole game. Land is one connected piece - every army
# reaches every other on its own feet, so the computer never needs the ferry it
# cannot plan - and the sea is one connected body every port opens onto, so
# fleets always find each other. Both at once is what the shape is for: the land
# is a tree (corner island -> causeway -> islet -> spine -> centre and back out
# again) with no loop in it and no cell touching the board edge, which is
# exactly the condition under which the water around it stays whole.
#
# Where this departs from the schematic: the spans are bridges, not shoals. A
# shoal costs every land class what road does, so a chain of them across water
# is a bridge the header never mentions - and the map lint says so out loud. The
# crossings are drawn as what they are, and the shoals stay what they are for:
# eight landing beaches on the island coasts where a lander puts armour ashore.
#
# The middle is the neutral chain - four cities on the two islets and, on the
# centre island, four more cities behind four neutral ports. Whoever holds the
# centre docks mid-sea and owns both crossings of the spine.
#
# Symbols: . plains  F woods  M mountain  = road  + bridge  C city  B base
#          Q HQ  P port  S sea  _ shoal  * reef
